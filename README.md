# HUMAN-CODE
This project represents the eighth exercise of the Web Development Master Course. It serves as an initial approach to JavaScript and programming logic by practicing the creation of "human-code" (pseudocode). The goal is to learn how to translate abstract human tasks into structured, step-by-step instructions that mirror computational logic.

# TASK
* Logical Decomposition: Breaking down complex real-world actions into atomic steps.
* Structured Thinking: Moving from vague descriptions to a rigorous, sequential "human-code" format.
* Algorithmic Foundation: Preparing the mental framework required to write formal JavaScript syntax.

## PROJECT STRUCTURE

```text
human-code/
```

## CONCEPTS
* Sequential Logic: Ensuring steps follow a functional order.
* Conditional Statements: Identifying "if/then" scenarios in everyday tasks.
* Loop Optimization: Recognizing repetitive actions using "for each" (to iterate through a set) or "until" (to continue until a goal is reached).
* Execution Safety: Defining clear exit conditions to ensure the process reaches a conclusion and avoids the logic error of an infinite loop.
